# NanoSolve Hive

> **Научно обоснованная информация о загрязнении нанопластиком и платформа сообщества для поиска решений.**

Мобильное приложение, которое предоставляет исследовательского уровня информацию о том, как нанопластик влияет на здоровье человека и окружающую среду, позволяет изучать научные источники и приглашает пользователей предлагать собственные идеи решений.

Доступно на **Android** (APK) · Создано на **Flutter** · Поддерживает **5 языков**

## Что делает приложение

NanoSolve Hive организовано вокруг двух ключевых вопросов:

- **Что нанопластик делает с нами?** — влияние на здоровье человека по 6 системам организма
- **Что он делает с планетой?** — экологический ущерб по 6 доменам экосистем

Помимо чтения материалов, вы можете отправлять собственные идеи по решению кризиса нанопластика, просматривать научные статьи за каждым утверждением и отслеживать, какие участники сообщества вносят наибольший вклад.

## Обзор приложения

### Онбординг

При первом запуске отображается вступление из 3 слайдов:

1. **Проблема** — масштаб загрязнения нанопластиком
2. **Миссия** — чего пытается достичь NanoSolve Hive
3. **Сообщество** — как решатели работают вместе

На первом слайде можно выбрать язык (английский, чешский, испанский, французский, русский). Выбор сохраняется, и повторно онбординг больше не показывается.

---

### Главный хаб

Центральный экран после онбординга. Интерфейс в стиле панели управления включает:

**Две вкладки воздействия (сверху)**

| Вкладка | Что охватывает |
|---------|----------------|
| Human | Как нанопластик попадает в организм человека и наносит вред |
| Planet | Как нанопластик повреждает океаны, атмосферу и экосистемы |

**Сетка категорий (по центру)** — по 6 карточек на вкладку. Нажмите на любую карточку, чтобы открыть экран с деталями.

*Категории Human:* Central Systems · Filtration & Detox · Vitality & Tissue · Reproduction · Entry Gates · Ways of Destruction

*Категории Planet:* World Ocean · Atmosphere · Flora & Fauna · Magnetic Field · Entry Gates · Physical Properties

**Центральный блок управления (снизу)**

| Кнопка | Действие |
|--------|----------|
| Human / Planet | Переключение активной вкладки |
| Sources | Открытие полной библиотеки материалов |
| Results | Статистика идей и лидерборд |
| Центральная шестерёнка | Открытие настроек |

**Интерактивный тур** — при первом запуске 6-шаговое руководство объясняет все элементы управления. Его можно пропустить в любой момент.

---

### Детали категории

Нажмите на карточку категории, чтобы открыть детальный экран.

**Что вы увидите:**

- **Ключевой тезис** — главное утверждение по категории с прямой ссылкой на нужную страницу исследования
- **Пункты списка** — поддерживающие доказательства и механизмы
- **Библиотека источников** — отдельный экран с научными ссылками, связанными с этой категорией

**Brainstorm Box** (внизу каждого экрана категории)

Здесь можно предложить свою идею решения проблемы нанопластика в данной области. При желании к идее можно прикрепить файлы (изображения, видео, аудио). Нажмите **Submit**, чтобы отправить её в backend сообщества. По умолчанию все отправки анонимны.

---

### Источники

Централизованная библиотека всех научных материалов, используемых в приложении.

**Карточка основного отчёта** — открывает полный Nanoplastics Global Report (198 страниц) во встроенном PDF-просмотрщике.

**Вкладка Web Links** — три раскрывающихся раздела:

| Раздел | Содержимое |
|--------|------------|
| Human Health | Научные статьи о влиянии на здоровье |
| Earth Pollution | Экологические исследования |
| Water Abilities | Материалы, связанные с водой |

Каждый элемент показывает диапазон страниц, к которому он относится в основном отчёте. Нажатие открывает PDF на нужной странице.

**Вкладка Video** — подборка YouTube-репортажей и видеоматериалов. Нажатие открывает их в браузере.

Фильтрация по языку применяется автоматически: при наличии вы увидите источники на выбранном языке, иначе используется английский.

---

### PDF Viewer

Открывается автоматически при нажатии на источник или карточку основного отчёта.

**Управление:**

| Элемент | Действие |
|---------|----------|
| Поле номера страницы (в заголовке) | Переход к любой странице |
| Кнопки ← / → (внизу) | Предыдущая / следующая страница |
| Кнопки + / − | Масштабирование от 1× до 5× |
| Жест pinch | Свободный зум |
| Иконка Share | Отправка PDF через другое приложение |
| Иконка Download | Сохранение PDF на устройство |

При повороте телефона в альбомный режим интерфейс перестраивается, текущая страница сохраняется.

---

### Results

Обзор активности сообщества:

- **Total Ideas** — общее число предложенных решений во всех категориях
- **Active Solvers** — общее число зарегистрированных участников
- **Панель оценки** — объясняет, как AI ранжирует присланные идеи

---

### Leaderboard

Рейтинг самых активных участников.

**Требование доступа:** сначала нужно зарегистрировать отображаемое имя и email. Нажмите **Register Now** и заполните короткую форму. Никнейм хэшируется перед сохранением, реальная личность не отображается.

После регистрации вы увидите:

- Значок ранга (gold · silver · bronze для топ-3)
- Имя участника и специализацию
- Количество принятых решений

Список обновляется автоматически. Потяните вниз, чтобы обновить вручную.

---

### Настройки

Доступны через иконку шестерёнки в центре хаба.

| Опция | Что делает |
|-------|------------|
| User Profile | Редактирование имени, email и описания специализации |
| Language | Переключение между EN / CS / ES / FR / RU |
| Privacy & Security | Политика конфиденциальности, условия использования, согласие на обработку данных |
| About | Версия приложения и проверка обновлений |

**Обновления (экран About)**

Приложение автоматически проверяет обновления через 5 секунд после запуска. Также можно запустить проверку вручную через иконку вверху экрана настроек. Если доступна новая версия, APK можно скачать и установить прямо из приложения с прогресс-баром и возможностью паузы или отмены.

## Поддержка языков

| Код | Язык | PDF в полной сборке |

| ES | Испанский | Да |

PDF на всех языках входят в приложение. Если какого-то нет, он загружается по запросу с сервера при переключении языка.

Переключение языка вызывает полный перезапуск приложения, чтобы весь интерфейс корректно обновился.

## Конфиденциальность

- Для чтения материалов и отправки идей **аккаунт не требуется**
- Для доступа к лидерборду нужен email и отображаемое имя, никнейм хранится как SHA-256 хэш
- User ID представляет собой случайно сгенерированный UUID, который хранится в зашифрованном локальном хранилище
- Настройки языка и тура сохраняются в обычных SharedPreferences
- Данные не продаются и не передаются третьим лицам

### UX Design System

Цель системы — адаптивность через токены, а не через ручное масштабирование отдельных виджетов. Все экраны используют `AppSpacing`, `AppSizing` и `AppTypography`, которые зависят от `ResponsiveConfig`. Благодаря этому приложение согласованно адаптируется к разным ширинам, высотам и ориентациям экрана.

Чтобы скорректировать поведение для нового размера экрана, достаточно изменить токены или добавить вариантную логику внутри токен-классов.

